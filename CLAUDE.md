# CLAUDE.md

Инструкции для Claude Code в этом репозитории.

## Что это за проект

Четыре скрипта на Python, которые восстанавливают медиатеку Apple Music после
смены страны Apple ID: читают выгрузку данных с privacy.apple.com, переводят
каталожные ID между витринами каскадом ISRC → прямой номер → `filter[equivalents]`
и заливают треки и плейлисты обратно через Apple Music API.

Зависимостей нет, только стандартная библиотека Python 3.9+.

## Документация двуязычная

Правило на все проекты: **английская и русская версии живут рядом и правятся
вместе**. Здесь это:

| Английская | Русская | Что внутри |
|---|---|---|
| `README.md` | `README.md` | обзор, установка, команды |
| `docs/FINDINGS.md` | `docs/FINDINGS.ru.md` | сырые замеры: охваты, точности, поведение API |
| `SECURITY.md` | — | предупреждения про токены |

Правишь одну версию — правь и вторую, иначе они разъезжаются.
`docs/article-habr-ru.md` — только на русском, это опубликованная статья.

## Что нельзя коммитить

`.gitignore` закрывает `tokens.json`, папку `work/`, все `*.csv` и саму
выгрузку Apple. Это не формальность: в отчётах лежит вся история прослушиваний
и Apple ID, а в `tokens.json` — ключи от чужой медиатеки.

## Где лежат замеры

Все проценты в README и в статье взяты из `docs/FINDINGS.md` — там же размеры
выборок и точные запросы. Новых цифр в документацию без замера не добавлять;
если Apple меняет поведение API, сначала перемерить первым скриптом
(`01_check.py`), потом править текст.
