# CLAUDE.md

Инструкции для Claude Code в этом репозитории.

## Что это за проект

Четыре скрипта на Python, которые восстанавливают медиатеку Apple Music после
смены страны Apple ID: читают выгрузку данных с privacy.apple.com, переводят
каталожные ID между витринами каскадом ISRC → прямой номер → `filter[equivalents]`
и заливают треки и плейлисты обратно через Apple Music API.

Зависимостей нет, только стандартная библиотека Python 3.9+.

## Документация двуязычная

Правило на все проекты: **английская и русская версии живут рядом и правятся
вместе**. Здесь это:

| Английская | Русская | Что внутри |
|---|---|---|
| `README.md` | `README.ru.md` | обзор, установка, команды |
| `docs/FINDINGS.md` | `docs/FINDINGS.ru.md` | сырые замеры: охваты, точности, поведение API |
| `SECURITY.md` | `SECURITY.ru.md` | предупреждения про токены и утечки |

Правишь одну версию — правь и вторую, иначе они разъезжаются.
`docs/article-habr-ru.md` — только на русском, это опубликованная статья.

На главной странице GitHub всегда показывается `README.md`, то есть английский:
выбирать версию по языку GitHub не умеет, русская доступна по ссылке в шапке.
Решение осознанное — местами их менять не надо.

## Что нельзя коммитить

`.gitignore` закрывает `tokens.json`, папку `work/`, все `*.csv` и саму
выгрузку Apple. Это не формальность: в отчётах лежит вся история прослушиваний
и Apple ID, а в `tokens.json` — ключи от чужой медиатеки.

Второй рубеж — `.githooks/pre-commit`. Он проверяет индекс и **блокирует**
коммит, если туда попали выгрузка, ключ, токен, дамп или файл крупнее 5 МБ, —
в том числе когда `.gitignore` обошли через `git add -f`. На маркеры
персональных данных (`Apple ID Number`, `House ID`, `IP City`) хук не
блокирует, а печатает предупреждение: эти строки законно встречаются в
`SECURITY.md` и в статье, поэтому решение остаётся за человеком.

Хук лежит в репозитории, но git не включает его сам — в свежем клоне надо
один раз выполнить:

```
git config core.hooksPath .githooks
```

Проверить: `git config core.hooksPath` должен вернуть `.githooks`.
Разовый обход — `git commit --no-verify`; постоянное исключение дописывается
в переменную `ALLOW` внутри хука (там уже лежит `tokens.example.json`).
