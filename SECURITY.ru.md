# Безопасность

**English version: [SECURITY.md](SECURITY.md)**

## К чему у инструмента есть доступ

Он работает с двумя токенами, которые вы кладёте в `tokens.json`:

- **developer token** — представляет клиента перед Apple;
- **music-user-token** — даёт полный доступ на чтение и запись к *вашей*
  медиатеке Apple Music.

Важен второй. Любой, у кого он есть, может читать вашу медиатеку, добавлять в
неё и удалять из неё — пока токен не истечёт (несколько месяцев).

## Правила

**Никогда не коммитьте `tokens.json`.** Он в `.gitignore`, но проверяйте перед
каждым пушем:

```bash
git status

# заполненные токены, в любом формате
grep -rIn -E '"(developer_token|music_user_token)"[[:space:]]*:[[:space:]]*"[^"<]{40,}"' . \
  --exclude-dir=.git

# JWT где угодно — например, случайно попавший в лог
grep -rIn -E 'eyJ[A-Za-z0-9_-]{20,}\.[A-Za-z0-9_-]{20,}' . --exclude-dir=.git
```

Оба шаблона проверены на настоящих токенах. Обратите внимание: токены Apple
**не** начинаются с привычного `eyJhbGciOi`, который обычно грепают — developer
token начинается с `eyJ0eXAi`, а music-user-token вообще не JWT. Поиск по имени
поля, а не по форме значения, обходит эту ловушку.

**Никогда не делитесь CSV-файлами из папки `work/`.** В них вся ваша история
прослушиваний и номер вашего Apple ID.

**Утёкший пользовательский токен отзывается** выходом из аккаунта на
[music.apple.com](https://music.apple.com): это делает недействительной куку, из
которой он взят. После этого войдите заново и получите новый.

## Что инструмент делает и чего не делает

- Обращается только к `api.music.apple.com` и `amp-api.music.apple.com`
- Никуда больше ничего не отправляет — ни телеметрии, ни аналитики, ни третьих
  сторон
- Не имеет зависимостей за пределами стандартной библиотеки Python, поэтому
  компрометировать через цепочку поставок нечего
- Пишет только в вашу медиатеку, только на шагах 3 и 4 и только с `--apply`

## Как сообщить об уязвимости

Про всё, что не является чувствительным, открывайте issue.

Если проблема может поставить под угрозу чужие аккаунты — токен, утекающий в
логи, непредусмотренный путь записи — сообщите приватно: через
[GitHub Security Advisories](../../security/advisories/new) или письмом на
**vdovikov@me.com**, а не публичным issue.

## К вопросу об условиях использования

Задокументированный способ получить developer token — программа разработчиков
Apple. Здесь описан и другой: взять токен, которым пользуется веб-плеер Apple
Music.

Этот путь ведёт к вашей собственной медиатеке с вашими собственными учётными
данными, ничего не обходит по оплате и не трогает чужие данные — но условиями
Apple такое применение не предусмотрено. Он предложен как осознанный выбор, а
официальный путь в README указан первым. Ни проект, ни его авторы не связаны с
Apple.
